# 调度器三阶段重构计划

> 当前步骤：步骤 1“调度循环修改”。顺序是依赖顺序：先让调度循环与修正后的新图一致，再重构事件源，最后实现可重入。步骤 2/3 的分析和设计尚未完成，不写可执行步骤。

## 背景与目标

- 新版设计已经画出“任务切换模型（新版调度算法）”，但图与文字设计、当前实现之间仍有不一致；先把图修对，再按图改调度循环。
- 调度循环稳定后，事件源需要按“调度与事件通信解耦”重新接入，避免通信逻辑继续渗进调度器。
- 最后实现调度器可重入：把调度器代码也视为任务的一部分，用嵌套现场和交接协议避免覆盖/重复/死锁。
- 非目标：本文档不补完所有 reference/design，不解决全部 Q，不在计划阶段改代码。

## 三个步骤

| 步骤 | 目标 | 前置 | 产出 | 状态 |
|---|---|---|---|---|
| 1. 调度循环修改 | 先整理并修正新图，再按图修改调度循环 | 图错误清单、图→代码映射 | 修正图 + `design/scheduling-loop` + 代码 | draft（当前） |
| 2. 事件源重构 | 按“调度与事件通信解耦”重新设计事件源接入方式 | 步骤 1、事件源分析/设计 | `design/event-source` + 代码 | blocked（分析/设计未完成） |
| 3. 调度器可重入 | 把调度器代码视为任务一部分，实现可重入 | 步骤 1/2、可重入分析/设计 | `design/reentrancy` + 代码 | blocked（分析/设计未完成） |

## 步骤 1：调度循环修改

以 [任务切换模型（新版调度算法）](../../draft/新版设计/任务切换模型（新版调度算法）.png) 为准；drawio 源文件在同目录。先修图，再改代码。

### 1.1 整理并修正新图

- 从 drawio/PNG 提取全部路径：入口（trap/thread）、保存、选择、切换地址空间/特权级、恢复、退出。
- 与文字设计 [全部路径枚举](../../draft/新版设计/共享调度器模块设计文档.md#全部路径枚举) 和当前 `src/main_loop.rs` 对照，列出图的错误/不一致。
- 已知待核对项（不预设结论）：
  - `trap_entry`/`thread_entry` 与 `ktrap_entry`/`utrap_entry` 的合并关系。
  - `trap_handler` 是否修改被 trap 任务状态，以及修改时点。
  - `TrapInfo` 在入口后入队，还是在 `trap_handler` 内入队。
  - 空栈/非空栈进入调度器，以及多核同步。
  - 全局最高优先级与“当前/全局比较”的路径。
  - `SCHEDULER_WAIT_CONTEXT` 的特殊路径。
  - `into_user`/用户栈、`run_task`/`krun_rtask` 的命名和职责。
- 修改 drawio，重新导出 PNG；在 `design/scheduling-loop` 写修正后的路径表、入口/出口、不变量和未决 Q。
- 完成标准：每条路径能对应到图中的节点/边；错误项有“已修/保留/转 Q”的结论。

## 步骤 2：事件源重构（分析/设计未完成）

规则：**调度与事件通信解耦**。调度器只消费“就绪任务 + 优先级”；事件源负责保存等待任务、接收/处理通信、把就绪任务交给调度器。通信识别、路由和完成通知不进入调度器主循环。

开始前必须先补：

1. 分析当前耦合点：`EventSource`/vtable、`Scheduler::sources`、trap/阻塞/waker 路径、外部事件源注册。
2. 设计事件源接入方式：注册/注销、生命周期、动态创建、per-CPU、优先级、与就绪队列的关系；给出接口变更表。
3. 再拆实现步骤和验证。

在这些完成前，不写可执行步骤；当前只登记为 blocked。相关 Q：Q-002、Q-023、Q-034、Q-037。

## 步骤 3：调度器可重入（分析/设计未完成）

思路：**把调度器代码也视为任务的一部分**。用户态调度代码被中断时，按“任务被中断”的路径保存嵌套现场，再由内核恢复；恢复旧现场不能回滚期间发生的唤醒/完成/退出。

开始前必须先补：

1. 分析嵌套现场的归属、发布时机、恢复顺序和容量。
2. 设计状态/action 与并发通知、执行权交接、跨特权级锁、`CURRENT_VSPACE`、栈保留/回收。
3. 再拆实现步骤和验证。

在这些完成前，不写可执行步骤；当前只登记为 blocked。相关 Q：Q-006、Q-008、Q-009、Q-010、Q-011、Q-012、Q-013、Q-014、Q-015、Q-018、Q-019。
